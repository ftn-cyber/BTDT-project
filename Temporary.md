# 1. Tentang BTDT

BTDT adalah bahasa pemrograman dan ekosistem yang dirancang untuk
mempermudah pengelolaan database kasir pada toko dan supermarket.

BTDT dirancang untuk menangani:

- Pengiriman data produk
- Penyimpanan database
- Pembaruan data
- Penyaluran data
- Autentikasi
- Penerimaan data pada sistem kasir

Spesifikasi ini bersifat sementara.
